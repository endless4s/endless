# Code of Conduct

*endless* is a [Typelevel affiliate project](https://typelevel.org/projects/affiliate/) and adopts the [Typelevel Code of Conduct](https://typelevel.org/code-of-conduct/).

We are committed to providing a friendly, safe and welcoming environment for all. Everyone is expected to follow the Typelevel Code of Conduct when participating in this project, including its issues, pull requests, discussions and any other communication channel.

The full text, including the standards of behavior, the consequences of violating them and the enforcement procedures, is maintained by Typelevel at <https://typelevel.org/code-of-conduct/>.

## Reporting

To report a possible violation or to ask a question about the Code of Conduct, please contact the [Typelevel Code of Conduct Committee](https://typelevel.org/code-of-conduct/#contact) or a member of this project.
